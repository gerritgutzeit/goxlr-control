# Abnahmekriterien

## Produkt

- [ ] Mini erkannt bei laufender Utility
- [ ] Windows-Audio läuft nicht über GoXLR (Default ≠ GoXLR)
- [ ] 4 Fader unabhängig konfigurierbar
- [ ] Fader steuert Master Volume
- [ ] Fader steuert App Volume
- [ ] Button löst konfigurierte Action aus
- [ ] Button kann Discord Mute-Shortcut senden
- [ ] Profile überleben Restart
- [ ] App-Zuordnung überlebt App-Restart
- [ ] Tray-Betrieb
- [ ] USB-Disconnect Recovery
- [ ] UI bleibt bei Disconnect bedienbar
- [ ] Kein stilles Device-Routing
- [ ] Local-only Kernfunktionen

## Qualität

- [ ] Unit-Tests für Engine-Kern grün
- [ ] Hardware-Protokoll ausgefüllt für H1–H9
- [ ] Self-contained Publish erstellt
- [ ] Bekannte Limits in README dokumentiert
