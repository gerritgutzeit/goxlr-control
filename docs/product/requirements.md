# Produktanforderungen

## Primärziel

GoXLR Mini als programmierbarer Windows-Controller ohne Audio-Routing über die Mini.

## Muss (MVP)

- Mini erkennen und verbinden (über Utility)
- 4 Fader unabhängig zuordenbar
- Master- und App-Volume
- Programmierbare Buttons (Mute, Media, Shortcuts, Discord Mute/Deafen)
- Profile persistent
- System Tray
- Reconnect bei USB/Utility-Unterbrechung
- Kein stilles Device-Routing
- Local-first

## Soll

- Soft Takeover Default
- First-Run Wizard
- Diagnostics + Export
- Follow Default Playback Device

## Später

- Lighting Sync
- OBS
- Discord confirmed mute (RPC)
- Auto Profile Switch
- Macros / Double-Press
